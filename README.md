# rust-external
This is my old rust source which was sadly leaked among us on the funny cheat website so I decided to fully release this as an official self leak rather than having a mangled version of it floating about.

This source isn't great but it's an okay learning resource if you want to start making stuff for rust, or if you just want a decent UI framework then here's one :)

This abused Noah's [hyper-reV](https://github.com/noahware/hyper-reV/) project which my friend modified a bit so we could use it on EAC safely, most definitely detected now though so use at your own risk. 

# Disclaimer
This source hasn't been updated in over 4 months (pre unity 6) so don't expect it to work out of the box

# Building
This project uses a vcpkg manifest file for freetype, glew, stb, spdlog, asmjit, xxhash, yoga, glm, curl, nohlmann-json and zydis

Figure out how to install [vcpkg](https://vcpkg.io/en/) here
